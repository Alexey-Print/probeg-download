# Пробег

Учёт пробега, моточасов, прогрева, замены масла и бензина. Для Android.

## [⬇ Скачать Пробег (APK)](https://github.com/Alexey-Print/probeg-download/raw/main/Probeg.apk)

1. Нажмите ссылку выше — скачается файл Probeg.apk.
2. Откройте его и разрешите установку из этого источника.
3. При первом запуске программа покажет номер — отправьте его владельцу, он пришлёт код доступа.

Обновления программа предлагает сама.
